# Introduction to Sequence Analysis for Life-Course Research
University of Helsinki, October 2026
Instructor: Joan Damiens

This repository contains the teaching materials for the doctoral course
Introduction to Sequence Analysis for Life-Course Research.

## Course structure

| Session | Topic |
|---|---|
| Lesson 1 | Building and describing sequences |
| Lesson 2 | Measuring similarity between trajectories |
| Lesson 3 | From distances to trajectory types |
| Lesson 4 | Linking trajectories to substantive questions |

## Materials

- `slides/` – lecture slides
- `syllabus/` – detailed session notes
- `labs/` – guided R scripts
- `lab_sheets/` – student lab sheets
- `data/` – synthetic teaching dataset
- `mini_project/` – assessment and report templates

## Software

The practical exercises use R, RStudio, TraMineR and WeightedCluster.
